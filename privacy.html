yt-studio – Privacy policy

Last updated: 2026-11-01

Who uses it

yt-studio is a single-user tool. Only the owner of the YouTube channel إزّاي؟ (@izzayrobi) uses it, on the owner's own computer.

What data it uses

  • With the owner's consent, it uses Google OAuth to get access to the owner's own YouTube channel: to upload and manage the channel's videos, captions and playlists, and to read the channel's YouTube Analytics reports.
  • The OAuth token is stored only on the owner's computer, in a file that only the owner can read.

What it does not do

  • It does not send Google user data to any server other than Google's APIs.
  • It does not sell, share or transfer Google user data to anyone.
  • It does not use Google user data for advertising.
  • It collects no data about other people.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

The owner can remove the tool's access at any time at myaccount.google.com/permissions, and can delete the token file on the computer.

Contact
